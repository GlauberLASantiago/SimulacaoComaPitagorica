Simulação da Coma Pitagórica
Uma simulação web interativa que demonstra a Coma Pitagórica e a "Quinta do Lobo" através da comparação de ciclos de oitavas e quintas perfeitas.

Esta ferramenta foi criada para fins educacionais, permitindo que estudantes e entusiastas da música visualizem e ouçam um dos problemas fundamentais da teoria da afinação.

❯ Funcionalidades
Geração de Intervalos: Calcula e exibe duas séries de notas: uma baseada em 7 oitavas perfeitas (razão 2/1) e outra em 12 quintas perfeitas (razão 3/2).

Sintetizador Polifônico: Toque múltiplas notas simultaneamente para comparar as afinações e ouvir as dissonâncias.

Normalização de Oitava: Transpõe todas as notas geradas para a mesma oitava, facilitando a comparação direta das alturas relativas.

Análise Comparativa: Mostra a diferença exata entre a 7ª oitava e a 12ª quinta em Hertz, Cents e Comas Pitagóricas.

Interface Interativa: Permite selecionar qualquer nota da escala cromática como ponto de partida e inclui uma explicação detalhada do experimento em um acordeão.

🚀 Como Usar
Como este é um projeto autocontido em um único arquivo HTML, não há necessidade de instalação ou build.

Clone o repositório:

git clone https://github.com/seu-usuario/seu-repositorio.git

Abra o arquivo index.html (ou o nome que você der ao arquivo principal) em qualquer navegador web moderno.

A simulação carregará com os valores padrão e estará pronta para uso.

🛠️ Tecnologias Utilizadas
HTML5: Estrutura da página.

Tailwind CSS: Estilização da interface.

JavaScript (ES6): Lógica da simulação e interatividade.

Tone.js: Geração de áudio e síntese sonora no navegador.
